# 종목 발굴 프로그램 (scout)

**지금은 잠잠하지만 6개월 안에 재평가될 수 있는 업종·종목**을 찾는 로컬 웹앱입니다.
한국(코스피·코스닥)과 미국 약 950종목을 대상으로, 주가가 아직 조용한 종목 중에서
"먼저 움직이는 것들"(내부자·기관 매수, 실적 추정치, 수주·증설·정책)이 겹치는 곳을 골라 줍니다.

> 조사 도구이며 투자 권유가 아닙니다. 점수는 "더 조사해 볼 만한 순서"이지 수익 예측이 아닙니다.
> 점수 공식의 가중치는 직접 정한 값이며, 과거 수익률로 검증(백테스트)한 것이 아닙니다.

## 실행

```bash
pip install -r scout/requirements.txt
python -m scout          # 브라우저가 http://127.0.0.1:8765 로 열립니다
```

저장소 맨 위 폴더(`kind-disclosure-tracker/`)에서 실행하세요. 내 PC에서만 접속됩니다.

## 화면

| 왼쪽 · 진행 | 가운데 · 후보 | 오른쪽 · 작업실 |
|---|---|---|
| ① 자료 받기, 투자 스타일, 출처별 수집 건수, 거시 환경, 작업 기록 | 추천 / 한국 / 미국 / 업종 / 제외됨 탭, 카드마다 4개 축 점수와 근거 | 사실 카드 · 시나리오 · 반론 검사 · 투자 메모 · 콘텐츠 대본 · 추적표 · 주간 섹터 브리핑 |

1. **① 자료 받기** — 처음엔 3~5분. 같은 날 다시 누르면 캐시 덕에 훨씬 빠릅니다.
2. 가운데에서 후보의 **선택**을 누르면 오른쪽에 문서가 만들어집니다. 탭을 바꾸면 다른 종류의 문서가 나옵니다.
3. 아래 입력칸에 추가 지시를 쓰고 **AI 해석**을 켠 뒤 **만들기**를 누르면 Claude가 같은 근거로 서술형 문서를 씁니다(키 필요).
4. **추적표에 추가** — 발굴한 날의 가격을 기록합니다. 6개월 뒤 시장 대비 수익률로 내 발굴이 맞았는지 대조합니다.

## 발굴 방법 (4개 축, 각 0~100점)

| 축 | 무엇을 보나 | 자료 |
|---|---|---|
| **소외도** | 6개월 시장 대비 수익률, 52주 범위 내 위치, 거래량·변동성 축소, 바닥 다지기 여부, 공매도 잔고, 낮은 PBR | Yahoo Finance 시세 |
| **스마트머니** | 한국: 외국인·기관 20일 순매수, 외국인 지분율 변화, 임원·대주주 매수, 5% 대량보유, 자사주 취득 / 미국: 내부자 장내 매수(Form 4), 유명 펀드 12곳의 신규 편입(13F) | 네이버 증권, 이 저장소의 KIND 공시 트래커, SEC EDGAR |
| **실적 추정** | 미국: 내년 EPS 추정치 90일 변화, 상향/하향 애널리스트 수 / 한국: 추정 EPS·영업이익 성장, 증권사 리포트 수와 논조, 손익구조 변경 공시, (키) DART 분기 영업이익, (키) 품목별 수출 | Yahoo Finance, 네이버 증권, DART, 관세청 |
| **촉매** | 신규시설투자·공급계약 공시, 다음 실적 발표일, 촉매 단어가 들어간 뉴스, 산업 리포트, 거시 환경이 유리한 업종 | KIND 공시 트래커, Google 뉴스, 네이버 리서치, 금리·원자재·환율, (키) FRED |

- **뜨거운 종목은 뺍니다**: 6개월 시장 대비 +25% 초과, 3개월 +40% 초과, 52주 고점 부근 → `제외됨` 탭.
- **후보 조건**: 소외도 40점 이상 + 다른 축 중 하나 이상 25점 이상.
- **추천 탭**: 서로 다른 축이 둘 이상 겹친 종목만, 업종당 3개까지.
- **투자 스타일**에 따라 시총 하한과 가중치가 달라집니다 — 균형형(한국 2,000억·미국 20억달러 이상), 공격형, 보수형. `scout/config.py`의 `STYLES`에서 고칠 수 있습니다.
- 미국 관찰 대상은 `scout/universe_us.json`(37개 산업 그룹)을 직접 고치면 됩니다. 한국은 네이버 업종 분류에서 자동으로 뽑습니다.

## API 키 (모두 무료 발급, 선택 사항)

화면 오른쪽 위 **설정**에 넣습니다. `scout/data/config.json`에만 저장되고 git에는 올라가지 않습니다.

| 키 | 켜지는 자료 | 발급 |
|---|---|---|
| DART 인증키 | 최근 정기보고서 영업이익의 전년 대비 증감 | https://opendart.fss.or.kr → 인증키 신청 |
| FRED API 키 | 미국 재고/판매 비율, 자본재 주문, 건축허가, 소비자심리 | https://fred.stlouisfed.org → My Account → API Keys |
| 공공데이터포털 키 | 관세청 품목별 수출(반도체·화장품·변압기·선박 등 13개 품목) | https://www.data.go.kr → "관세청_품목별 수출입실적" 활용신청 |
| Claude API 키 | AI 해석(서술형 메모·반론·대본). 사용량만큼 과금 | https://console.anthropic.com |
| SEC 연락처 이메일 | SEC가 자동 접속에 요구하는 값. 본인 이메일 권장 | — |

키가 없어도 나머지 자료로 동작합니다.

## 알아 둘 한계

- **DART·FRED·관세청 연동은 키 없이 만들어 실제 응답으로 검증하지 못했습니다.** 키를 넣고 처음 돌릴 때 왼쪽 "자료 출처"에 `실패`가 뜨면 알려 주세요.
- **Claude AI 해석도 실제 키로 끝까지 실행해 보지는 못했습니다**(잘못된 키를 넣었을 때의 안내까지만 확인).
- 한국 종목의 "실적 추정"은 추정치의 *수준*(최근 실적 대비)을 봅니다. 추정치의 *방향*(상향·하향)은 이 프로그램이
  실행될 때마다 추정 EPS를 기록해 3주 뒤부터 비교합니다. 주 1회 이상 돌리면 쌓입니다.
- 네이버·Yahoo·Google 뉴스는 공식 API가 아니어서 주소나 형식이 바뀌면 해당 출처만 `실패`로 표시됩니다.
- 13F는 분기 말 기준 45일 뒤에 공개되는 늦은 자료입니다. 회사명으로 맞추기 때문에 일부는 놓칩니다.
- 뉴스 촉매는 제목의 단어로만 판단하므로 무관한 기사가 섞일 수 있습니다. 원문 링크로 확인하세요.
- KIND 공시 트래커 자료(`docs/data/all.json`)는 `git pull`로 최신화됩니다.

## 파일

```
scout/
  server.py      로컬 서버 (127.0.0.1:8765)
  pipeline.py    수집 순서와 점수 계산
  universe.py    관찰 대상 (한국: 네이버 업종 / 미국: universe_us.json)
  prices.py      가격 지표와 소외도
  sources_kr.py  수급·컨센서스·리포트·공시·DART·수출
  sources_us.py  Form 4 · 13F · 추정치
  macro.py       거시 환경, 뉴스
  writer.py      문서 생성 (규칙 기반 + Claude)
  store.py       추적표, 주간 브리핑
  static/        화면
  data/          받은 자료·설정·만든 문서 (git 제외)
```
